# 三国志マップ

三国志をゼロから、地図と年表でたどる学習ゲーム（第1章：184年 黄巾の乱〜208年 赤壁の戦い）。

## 起動のしかた

```bash
npm install   # 最初の1回だけ
npm run dev
```

表示された `http://localhost:5173/` をブラウザで開く。
スマホ1画面（390×844）をウィンドウに合わせて拡大縮小して表示します。
ブラウザの開発者ツールでスマホ表示にすると、実機に近い見え方で確認できます。

## 中身の場所

| 変えたいもの | ファイル |
| --- | --- |
| イベント（問題・正史/演義の解説・もらえるカード） | `src/data/events.ts` |
| 武将（見た目の色・図鑑の紹介文） | `src/data/characters.ts` |
| 地図（州の配置・年ごとの勢力図） | `src/data/map.ts` |
| 画面 | `src/screens/` |
| ちびキャラの絵 | `src/components/Chibi.tsx` |

進み具合（モード・ポイント・カード）はブラウザの localStorage に保存されます。
最初からやり直すときは「設定 → きろくを最初からにする」。
